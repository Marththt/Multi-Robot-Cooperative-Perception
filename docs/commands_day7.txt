2) PC1: one block, about 6-7 hours (5 trainings of ~75 min + segmentation + tests); can run overnight.

------------------------------------------------------------------
What it does, in order:
  a. prompt check: 4 text prompts on 9 layouts (figure + table in run_day7.log), ~5 min
  b. all 444 real scenes in the network format, every camera calibrated on its own run (masks from the caches)
  c. mask network: seeds 1 and 2 (seed 0 = masks_wp, already trained), same recipe
  d. mask + marker network with the real marker detection rates (--marker-rates): seeds 0, 1, 2
  e. every network tested on the 444 scenes, per frame and with the 5 frames of each stop fused
  f. commit and push
