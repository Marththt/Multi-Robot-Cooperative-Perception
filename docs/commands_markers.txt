IMAGE NETWORK WITH THE MARKER CHANNEL (masks_mk)
=================================================
Input per image: B = box mask, G = ArUco detections (filled rectangles), R = box mask.
Sim: markers detected only if the centre is visible, p = 0.93, falling with viewing angle (55->75 deg)
and distance (1.8->2.6 m, as measured on the real campaigns); half of the obstacles/distractors are white
(they appear in the mask like a box, but carry no marker).
Training: --marker-dropout 1.0 (25% of images without any marker, 15% of markers missed, a few false ones),
so the network must still work from the mask alone.

------------------------------------------------------------------
4) PC1: training (same settings as masks_wp + marker dropout)
------------------------------------------------------------------
python -m bevnet.train --train data/bev_mask_mk/train --val data/bev_mask_mk/val --tests "data/bev_mask_mk/G0_*" "data/bev_mask_mk/E3_*" "data/bev_mask_mk/S1_*" --out results/bev_mask_mk/ --name masks_mk --channels 64 --encoder small --pitch-noise 1.5 --yaw-noise 1.0 --height-noise 0.025 --mask-noise 1.0 --marker-dropout 1.0 --max-val 2000 --workers 8
