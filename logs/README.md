# Logs of the PC1 runs

Logs of the runs that produced the results in `results/` (day 6, day 9, day 10 blocks, M4 on the real scenes), kept
as a record of where the numbers come from.

The only script still in use is `run_grid.bat` (robots x boxes grid 2-50: MHT, marker network, YOLO + marker
network). It `cd`s to its own folder, so it is copied to the repository root and started by
`docs/paste_in_powershell_PC1_grid.txt`.
